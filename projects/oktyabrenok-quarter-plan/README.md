# «Кто такой Октябренок?» — план на четверть

Документ: `PLAN.md` (исходник) → `plan.pdf` (28 страниц, A4, для печати).

## Что внутри

Система шефского наставничества «4 + 1»: **шефы — 4-й класс**,
**подшефные — 1-й класс**. Ритм недели: Пн «Весёлые старты» →
Вт «Творческая мастерская» → Ср «Краевед» → Чт «Труд крут!» →
Пт «Знай, умей!» → Сб «Литературная шкатулка» (6-й школьный день),
поверх них сквозные ритуалы «Невидимой поддержки», еженедельный
**«Час Огонька»** (среда, 4-й урок) и 3 пионерских сбора.
Плюс календарь на 10 недель, банк игр под 1 класс, учёт, риски, приложения.

## Пересобрать PDF

```sh
npm install          # единственная зависимость — marked
node build.mjs       # PLAN.md -> plan.html -> plan.pdf
```

PDF печатается headless-браузером Chrome (на этой машине `pandoc` и `brew`
нет, `brew install pandoc` тоже работает, но не требуется). Стили и обложка
лежат в `build.mjs`, шаблон один — правьте CSS-блок `CSS`.

Параметры печати: A4, поля 18/16 мм, колонтитулы отключены
(`--no-pdf-header-footer`), каждый раздел `##` начинается с новой страницы,
таблицы не разрываются между страницами.
