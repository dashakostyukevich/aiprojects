# ugc-creator-portfolio

UGC creator portfolio website. Plain HTML, CSS and JavaScript — no build step, no dependencies.

The building rules are in `CLAUDE.md`. Read it first; it decides how every change is made.

## Structure

```
index.html          the whole page
css/styles.css      all colours, fonts and spacing live here
js/main.js          small behaviour (video handling, menu)
assets/             images: photo, share preview, favicon
media/              videos and their cover images
```

## Working on it

Double-click `index.html` to see the site in your browser. Refresh to see changes.

Save points are kept in git history, one per finished section. No GitHub account is needed.
