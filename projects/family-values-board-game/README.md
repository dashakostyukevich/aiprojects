# Семейные ценности — настольная игра

Печатный макет настольной игры для учащихся 3 класса по дополнительной общеразвивающей
программе «Я. Моя семья. Моя Родина».

**Цель:** формирование представлений о социальных ролях (сын/дочь, внук, брат/сестра,
друг, ученик, октябрёнок); воспитание уважительного отношения к семье и чувства гордости
за свою семью; сплочение членов октябрятской группы через совместную игровую деятельность.

## Готовый файл для печати

```
dist/Семейные ценности — 3 класс.pdf   — 14 листов A4, готов к печати
```

Распечатать в масштабе 100 % на плотной бумаге 160–200 г/м². Поле и карточки лучше
цветные; кубик, фишки и жетоны можно вывести на картон.

## Состав комплекта

| Стр. | Материал | Что это |
|-----:|----------|---------|
| 1 | Обложка | Цель, состав, правила, таблица расхода бумаги |
| 2 | Игровое поле | 36 клеток змейкой, 5 цветовых секторов, легенда |
| 3–7 | Карточки | 5 колод по 6 карточек — всего 30 |
| 8 | Кубик, фишки, жетоны | Развёртка кубика, 6 фишек, 20 жетонов |
| 9 | Памятка игрока | Ход, начисление жетонов, особые клетки, 3 правила игры |
| 10 | Карточка рефлексии | Роли с чекбоксами + поля для ответов |
| 11–14 | Методическая разработка | Пояснительная записка, результаты, ход занятия, приложения |

## Пять колод карточек

| Сектор | Клетки | О чём |
|--------|-------:|-------|
| **Роль** | 2–7 | сын и дочь, внук и внучка, брат и сестра, друг, ученик, октябрёнок |
| **Ценность** | 8–13 | уважение, забота, ответственность, доверие, терпение, доброта |
| **Дело** | 14–19 | порядок, посуда, растения и питомцы, готовка, комната, помощь |
| **Традиция** | 20–25 | Новый год, 8 Марта, День семьи, гости, поездка к родным, День России |
| **Слово** | 26–31 | род, родня, поколение, традиция, ценность, ответственность |

Каждая карточка: название, короткое определение, подсказка учителю и задание команде.
Все формулировки готовы к печати — дописывать ничего не нужно.

## Правила

Команда бросает кубик и двигает свою фишку. Карточку берёт игрок, бросивший кубик,
отвечает вся команда. На ответ — 1 минута. Верный ответ даёт жетон ценности.
Первое место на Финише — +3 бонусных жетона. Побеждает команда с наибольшим числом жетонов.

Особые клетки 32–35: «+2», «Ход», «Команда», «Тепло». Клетка «Тепло» просит сказать
доброе слово о семье соперника — это снимает напряжение соперничества.

## Правила игры для детей (на памятке)

1. **Слушаем** — говорит один, остальные дополняют.
2. **Не смеёмся** — обсуждаем идею, а не человека.
3. **Говорим о себе** — ответ должен быть настоящим: «я делаю…», «у нас в семье…».

## Сборка

```sh
python3 tools/generate.py            # HTML + PDF
python3 tools/generate.py --no-pdf   # только HTML
python3 tools/check_overflow.py      # проверка: ничего не выходит за край листа
python3 tools/preview.py 2 8 11      # PNG-превью выбранных страниц
```

`generate.py` — единственный источник правды. Весь контент (тексты карточек, методичка)
лежит в нём как данные; `print/index.html` и PDF пересобираются из него.
Правьте тексты в Python, а не в готовом HTML.

Требуется Google Chrome — PDF собирается headless-режимом.
Системный `python3` (3.9) подходит, дополнительных пакетов не нужно.

## Проверка качества

`tools/check_overflow.py` измеряет реальную высоту содержимого каждой страницы и падает
с кодом 2, если что-то вылезло за край A4. Сейчас все 14 страниц проходят.

`tools/preview.py` рендерит отдельные страницы в PNG — так видно проблемы, которые
не ловятся числами (наложения, переносы, обрезка).

Обе проверки ловят то, что не видно в коде: PDF собирался из 12 страниц вместо 14,
пока в разметке не хватало одного `</div>`, а развёртка кубика не складывалась в куб.

## Структура

```

print/styles.css          стили печати A4
```
